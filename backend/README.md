# DentUz Backend API

Kelgusi versiyalarda Node.js (Express / NestJS) yoki Python (FastAPI) orqali backend API va PostgreSQL ma'lumotlar bazasi integratsiyasi amalga oshiriladi.

### Rejalashtirilgan modullar:
- Bemorlar kartochkasi va tibbiy tarix (RESTful API)
- Randevu taqvimi va band qilish tizimi
- Odontogramma saqlash va tish holati tarixi
- Moliyaviy operatsiyalar va hisob-fakturalar
- SMS (Eskiz) va Telegram Bot orqali bildirishnomalar yuborish
- JWT asosidagi avtorizatsiya va rollar (Admin, Shifokor, Hamshira)
